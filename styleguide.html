Design report · 2026

Prague.bio design system

Built on Tailwind CSS v4 with our own tokens. One set of components, three themes, a clear scale for type, spacing and radii, and one motion language.

Themes

Main web is light. The conference sub-site is dark navy with neon accent, the Executive Academy uses violet. Sub-sites use the split header with “← Prague.bio”. The footer is always dark and takes the tint of the theme.

Spacing & radii

Spacing – base 4 px

  • Section · 64 → 128 px · .section, var(--section-y)
  • Block · 40 – 64 px · between header and content
  • Group · 16 – 24 px · items in a grid / stack
  • Card padding · 20 → 32 px · .card-pad
  • Control · 12 – 16 px · inside buttons and inputs
  • Gutter · 20 → 72 px · .wrap side padding

Radius scale

Nested element = parent radius − its padding. One step smaller on mobile.

  • xs · 6tags
  • sm · 10small buttons
  • md · 14controls
  • lg · 22cards
  • xl · 32media
  • 2xl · 44hero, bands
  • 3xl · 64footer
  • full · 999chips, pills

Icons

Phosphor Light, stored locally in src/icons. Every page gets an inline sprite with only the icons it uses. Usage: {{ icon('arrow-right') }}.

Motion

Hover · 200 ms

Color, border, lift by 2–4 px. ease-out-expo.

UI · 400 ms

Menus, accordions, tabs, modals (bottom sheet on mobile).

Reveal · 900 ms

Fade-up on scroll, headings by words, staggered groups. Gradient words drift slowly (10 s). Disabled for prefers-reduced-motion and ?static.
